# Migrações adiadas

Os scripts desta pasta ainda não devem ser aplicados. Mova o script para `supabase/migrations` somente depois de publicar e verificar a versão do app que lê e grava exclusivamente pelas rotas de servidor. A migração revoga o acesso direto aos dados e às funções públicas; aplicá-la antes da implantação interrompe o site atual.

`xml_nfse` fica fora do escopo destas alterações.
